## Download

**JobDesk-…-windows.zip** below. Unzip it anywhere and double-click `JobDesk.exe`. The dashboard opens in your browser, and closing the console window stops it. No Python or Node needed.

Windows may warn that the app is from an unknown publisher, because it isn't code-signed. Choose **More info → Run anyway**.

Your data goes in `%APPDATA%\JobDesk`: the database, attached files, backups and `settings.json`. A new version reads the same data, so to update you replace the folder.

To give Claude access through MCP, point your MCP client at `JobDesk.exe` with the argument `mcp`. The README shows how.
